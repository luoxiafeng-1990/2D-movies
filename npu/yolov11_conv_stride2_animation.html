操作说明

蓝色粗框 = 3×3 卷积核的当前位置 | 绿色高亮 = 被覆盖的像素 | 红色高亮 = 输出结果位置

stride=2 时卷积核每次跳 2 格，输出 = (N−3+2)/2+1 = N/2，正好缩小一半

尺寸计算公式

通用公式（高、宽算法相同）：

Hout = ⌊(Hin + 2P − K) / S⌋ + 1

Hin = 输入边长  |  K = 卷积核边长  |  S = 步长 stride  |  P = 单边 padding

3×3 卷积时，padding 通常取 P = ⌊K/2⌋ = 1（上下左右各补 1 圈）。上面简化写法 (N−3+2)/S+1 就是 K=3、P=1 时的特例。

YOLO 真实例子：输入 640×640，K=3，S=2，P=1

Hout = ⌊(640 + 2×1 − 3) / 2⌋ + 1 = ⌊639/2⌋ + 1 = 319 + 1 = 320

所以：640×640 → 320×320（边长正好减半）。YOLO11 连做多次：640→320→160→80→40→20。
